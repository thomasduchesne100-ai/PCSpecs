Installation en 3 étapes

Pas de programme d’installation : un seul fichier.

  1. TéléchargeClique sur « Télécharger pour Windows » pour récupérer PCSpecs.exe.
  2. Place-leMets le fichier dans un dossier fixe, par exemple C:\PCSpecs.
  3. Lance-leDouble-clique sur PCSpecs.exe. C’est tout.

Questions fréquentes

 

Windows affiche « Windows a protégé votre ordinateur ». Que faire ?

C’est normal pour une petite appli non signée. Clique sur « Informations complémentaires », puis sur « Exécuter quand même ».

L’appli est-elle gratuite et sûre ?

Elle est gratuite. PCSpecs ne fait que lire les informations de ton PC, rien n’est envoyé sur Internet.

Pourquoi les températures ne s’affichent pas ?

Windows ne donne pas toujours accès aux capteurs. Sur certains PC, l’information est simplement indisponible.

Comment mettre à jour ou désinstaller ?

Pour mettre à jour, remplace l’ancien PCSpecs.exe par le nouveau. Pour désinstaller, supprime simplement le fichier.
